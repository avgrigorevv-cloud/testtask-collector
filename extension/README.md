# Скриншоты с метками (расширение для Chrome)

Расширение для Chrome и браузеров на его движке (Яндекс, Edge, Brave). Делает скриншот
видимой части страницы и открывает поверх нее редактор: метки с комментариями, области,
замер отступов между элементами, обрезка. Результат копируется в буфер обмена одной
кнопкой. **Все работает локально в браузере, ничего не отправляется в интернет.**
Сохранение на собственный сервер (папки по логинам и датам) есть, но необязательно.

## Установка

**Из магазина (за пару кликов):** Opera Add-ons (Opera и Яндекс Браузер), Edge Add-ons,
Chrome Web Store → «Установить». Ссылки появятся после публикации (см. `STORE.md`).

**Из исходников (без магазина):**
1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное» → папка `extension/`.

## Как пользоваться

1. Нажмите на иконку расширения → **Сделать скриншот** (или `Alt+Shift+S`).
2. **Один клик** по скриншоту ставит метку-точку, **зажать и протянуть** рисует область.
   Метку-точку можно перетащить. **+ Добавить метку** под списком кладет метку в центр.
3. У каждой метки свой комментарий. Переключатель **«Рядом с меткой»** рисует комментарий
   прямо возле метки, иначе он идет списком под картинкой.
4. **Сетка**: замер отступов как в режиме разработчика. Наведите на элемент страницы:
   пунктирные направляющие по его краям и расстояния до родителя в px (CSS-пикселях).
   Клик закрепляет замер, Shift+клик и затем клик по второму элементу измеряет
   расстояние между двумя элементами, Esc отменяет выбор, «Очистить замеры» убирает
   закрепленные. **Удерживание Option (Alt)** включает замер на время, не выключая
   режим меток.
5. **Обрезать**: выделите область и нажмите зеленую ✓ под правым нижним углом картинки
   (✕ отменяет). Метки внутри области сохраняются, остальные удаляются.
   **Вернуть исходный** появляется после любой правки и отменяет все.
6. **Копировать** (кнопка внизу или иконка с двумя квадратами над скриншотом) кладет в
   буфер обмена одну картинку: скриншот с метками, замерами и списком комментариев под
   ним. Вставляется как рисунок в PowerPoint, Word, Figma, чаты и почту.
   `Esc` закрывает редактор (если есть правки, нужно нажать дважды).

## Ограничения

- Снимается только видимая часть окна, без прокрутки.
- На служебных страницах (`chrome://`, магазин расширений, встроенный просмотр PDF)
  браузер не дает расширениям делать скриншоты, расширение показывает понятную ошибку.
- Замер использует расположение элементов в момент скриншота: iframe и содержимое вне
  видимой области не измеряются.

## Свой сервер (необязательно)

Если нужно хранить скриншоты на сервере: поднимите сервис из этого репозитория (см.
корневой `README.md`: `.env`, `prisma migrate deploy`, `npm run ext-user -- <логин> <пароль>`),
затем в попапе расширения раскройте «Сохранять на свой сервер» и введите адрес, логин и пароль.
Адрес `https://` обязателен, `http://` разрешен только для `localhost`. Скриншоты ложатся в
`uploads/captures/<id логина>/<ГГГГ-ММ-ДД>/` и видны в админке (вкладка **Скриншоты**).
На сервере в `EXT_ALLOWED_ORIGINS` можно указать ID расширения
(`chrome-extension://<id>`), тогда API примет запросы только от него.
Без входа расширение продолжает работать в локальном режиме.
