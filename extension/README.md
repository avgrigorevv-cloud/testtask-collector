# Расширение «Скриншоты с метками»

Расширение для Chrome (и браузеров на его движке: Яндекс, Edge). Делает скриншот видимой
части любой страницы. Поверх страницы открывается редактор: клик ставит пронумерованную
метку, к каждой метке пишется комментарий, есть общий комментарий. После сохранения
скриншот уходит в сервис тестовых заданий, в папку того логина, под которым вошли.

Механика меток та же, что в блоке «Разметка скриншотов»
(`src/components/shared/ImageAnnotate.tsx`): координаты в процентах, формат
`{ imageIndex, x, y, comment }`. Поэтому админка показывает скриншоты тем же компонентом.

## Установка (пока без Chrome Web Store)

1. Откройте `chrome://extensions` и включите «Режим разработчика».
2. Нажмите «Загрузить распакованное» и выберите папку `extension/`.
3. Закрепите иконку на панели (значок пазла → булавка).

## Как пользоваться

1. В админке сервиса откройте **Скриншоты**, создайте логин и пароль для сотрудника.
2. Сотрудник нажимает на иконку расширения, вводит адрес сервиса, логин и пароль.
   Chrome один раз спросит разрешение на доступ к адресу сервиса.
3. На нужной странице нажмите **Сделать скриншот** или `Alt+Shift+S`.
4. Кликайте по скриншоту, пишите комментарии, нажмите **Сохранить**.
   `Esc` закрывает редактор (если уже есть метки, нужно нажать дважды).
   Над скриншотом:
   **Сетка** (дизайн-сетка в пикселях страницы: «Квадраты» с шагом 4/8/10/16/24/32 px
   или «Колонки» с числом колонок, полями и зазором; нужна для проверки отступов, при
   включенной сетке она попадает и в копию, и в сохраненную картинку с метками),
   **Область** (протяните рамку по элементу: рамка с номером и комментарием, режим
   выключается повторным нажатием) и
   **Обрезать** (выделите область → зеленая ✓ под правым нижним углом картинки (✕ отменяет); метки внутри области сохраняются,
   остальные удаляются; **Вернуть исходный** отменяет обрезку).
   Одна иконка **копирования** (два квадрата) за одно нажатие кладёт в буфер обмена картинку:
   скриншот с метками, а под ним заголовок страницы, адрес и список комментариев
   (текст нарисован в самой картинке; у каждого комментария есть переключатель
   «В списке под фото» / «Рядом с меткой»: второй вариант рисует комментарий прямо возле метки; поэтому вставляется вместе с ней в PowerPoint, Word, чаты).
   Сохранение на сервер остается как было.
5. Скриншоты лежат в админке: вкладка **Скриншоты → папка логина → блоки по датам**
   (на диске: `uploads/captures/<id логина>/<ГГГГ-ММ-ДД>/`). Там можно скачать PNG с
   нанесенными метками или оригинал.

## Что отправляется на сервер

`POST /api/ext/captures` (Bearer-токен): оригинальный PNG, PNG с нарисованными метками,
метки с комментариями, общий комментарий, адрес и заголовок страницы, размер окна.

## Ограничения

- Снимается только видимая часть окна, без прокрутки.
- На служебных страницах (`chrome://`, магазин расширений, встроенный просмотр PDF)
  браузер не дает расширениям делать скриншоты, расширение показывает понятную ошибку.
- Адрес сервиса по умолчанию `https://task.uxteam.space`. Его можно поменять при входе.
